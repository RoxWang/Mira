Mira — 怎么用

一个为碎片时间设计的本地视频播放器。三种方式，随便选。

▶ 免下载，直接用网页版 点一下就能播，不用安装、不用更新 — 推荐大多数人用这个

网页版就是 Mira 本体，功能最全、永远最新。

三种方式，自由选

推荐网页版（全平台 · 免安装）
  • 点上面按钮直接打开即用，不占空间、不用更新。
  • 联网就能用，永远是最新版。
macOSMac App（离线 · 双击直开）
  • 下载 Mira-1.0.zip → 解压得到 Mira.app → 拖进「应用程序」。
  • 额外能力：整季自动串联、设系统默认播放器、完全离线。
  • 仅 macOS。
全平台离线 HTML（任意系统）
  • 下载 Mira-standalone.html，双击就能用，不用联网、不用装 app。
  • 适合 Windows / Linux，或想纯本地离线的人。

我实测过的结论（已真机验证）

✓ 默认浏览器同步逻辑已跑通

  • 在 App（或网页 Mac 端）里选默认浏览器 → 配置落盘 → 下次双击开视频真的用那个浏览器。
  • Chrome / Safari / 恢复系统默认，三步全部验证通过。

下拉顺序：系统默认 → ① 谷歌 → ② Edge → ③ Safari → ④ 火狐 → 其余（Brave / Vivaldi / Opera / Arc / Chromium）。

一点提醒：网页端选的浏览器，仅对 macOS 的 Mira.app 生效；非 Mac 设备只在本地保存，不会真正改系统打开方式。Mac App 里选则是最终生效端。
