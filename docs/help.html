Mira — 怎么用

极简本地视频播放器。视频在你自己硬盘上，不上传、不联网。

▶ 免下载，直接用网页版 点一下就能播，啥都不用装 — 推荐大多数人用这个

怎么用（一句话）

打开上面的链接 → 点「打开视频」选文件（或拖进页面）→ 看完关掉，下次自动接着播。手机、电脑、平板都一样。

选哪个版本（挑一个就够了）

你的情况用这个怎么弄
大多数人网页版直接打开链接，永远最新，无需任何操作
想要桌面图标、不占空间浏览器「安装为应用」打开链接 → 浏览器菜单 → 安装此站点为应用（和网页同一套，无下载）
Mac 用户，要双击直开 / 整季自动连 / 断网Mira.app（仅 macOS）① 点 Releases → ② 点 Mira-1.0.zip 下载 → ③ 双击解压得到 Mira.app → ④ 拖进「应用程序」文件夹

Mac 端已实测（真机跑通）

✓ 在 App 或网页 Mac 端选默认浏览器 → 下次双击开视频就真用那个浏览器（Chrome / Safari / 恢复默认都验证过）。

下拉顺序固定：系统默认 → ① Google Chrome → ② Microsoft Edge → ③ Safari → ④ Firefox → 其余。
注意：网页端的选择只对 macOS 的 Mira.app 生效；非 Mac 只存本地，不会真改系统打开方式。
