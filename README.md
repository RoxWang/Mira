# Mira — 极简本地视频播放器

> **打开就能用，不用下载、不用安装、不用注册：**
> ### 👉 https://roxwang.github.io/Mira/
>
> 这是一个**跑在浏览器里的**本地视频播放器。视频文件永远留在你电脑 / 手机的硬盘上，不上传、不联网、不留副本。
> Windows、macOS、iPhone、iPad、Android —— 只要有浏览器，打开上面那个网址就能看。

一句话说清它是什么：**它不是软件，是一个网页。** 你在网页里选自己的视频文件，它负责把片子放好、记住你看到哪儿、把字幕挂上。

## 怎么用（三步）

1. 浏览器打开 **https://roxwang.github.io/Mira/**（手机也一样，直接输网址或扫码）。
2. 点「打开视频…」选一个文件，或点「打开文件夹…」选一整部剧，也可以直接把视频/文件夹拖进页面。
3. 看完关掉就行。下次打开同一个网址，主页会显示「继续播放」，点一下接着上次那一秒。

**想分享给别人？** 把这个网址发给他就行：`https://roxwang.github.io/Mira/`
不用他装任何东西，手机上也能直接开。

## 特性

- **继续播放**：按「剧名 + 第几集」记住位置，关掉再开接着看
- **播放列表**：选整个文件夹或一次选多集，自动按集数排序
- **双字幕**：主 / 辅独立，位置 / 大小 / 颜色 / 延迟都能调，同目录字幕自动挂上
- **画面调节**：亮度 / 对比 / 饱和 / 色相 / 旋转 / 缩放 / 比例
- **断网也能开**：页面会在浏览器里存一份，第二次起没网也打得开（视频本来就在你硬盘上）
- **零联网、零转码、零缓存**：视频原地播放，不生成任何副本

## 三种打开方式，差别到底在哪

同一个播放器，三种入口。**先看这张表，就不会下错东西。**

|  | 网页（输网址） | 浏览器「安装页面为应用」 | Mira.app（下载 zip） |
|---|---|---|---|
| 怎么开 | 打开网址 | 浏览器菜单 →「安装页面为应用」 | 双击图标，或双击视频文件 |
| 要不要联网 | 要 | 要 | **不要** |
| 双击视频就能播 | ✗ 得先开网页再选文件 | ✗ 同左 | **✓ 直接播** |

| 设为系统默认播放器 | ✗ 浏览器不允许 | ✗ | **✓**（唯一的独占能力） |
| 谁是新的 | 永远最新 | 永远最新 | 打包那一刻的快照，更新要重下 |

一句话：**网页版功能是全的**，缺的只有「双击视频直接开」「自动把同目录整季串起来」「浏览器不认的容器自动转封装」这三件——这三件恰恰都需要读你硬盘上的文件夹，浏览器出于安全不给，只能靠本地那个 app 干。

## 关于下载（先说清楚，别下错）

**绝大多数人不需要下载任何东西。** 上面那个网址在 Windows / Mac / 手机 / 平板全都能用。

[Releases](https://github.com/RoxWang/Mira/releases) 里那个 `Mira-1.0.zip` 是**给 macOS 用户的可选工具**：

- 它**不是另一个播放器**，里面装的就是同一份播放器页面。
- 它比网页多做的三件事，都在双击的那一瞬间由本地脚本完成（网页做不到，因为网页读不到你的文件夹）：
  1. 拿你双击的那个视频，把**同目录的整季**读成播放列表；
  2. 把同目录**同名字幕**（含 `.zh-Hans` / `.dual` 这类）一次读好挂上 —— 网页版要你自己去选文件夹；
  3. 本机装了 ffmpeg 的话，遇到 Chrome 不认的容器（mkv 等）自动转封装成 mp4 再播。
- 它**只能在 macOS 上运行**。用哪个浏览器打开 = **你系统的默认浏览器**（Chrome / Edge / Brave / Vivaldi / Safari 都行），不弹任何窗。
- 想换浏览器：系统设置 → 桌面与程序坞 → 默认网页浏览器，改完下次双击视频就生效。想固定用某个而不动系统设置，把 bundle id 写进 `~/Library/Application Support/Mira/browser` 一行，例如 `com.google.Chrome`。
- 它里面是**打包那一刻**的页面副本：网页更新了它不会自己变，要用新版得重新下 zip。
- **Windows 上不要下这个**，Windows 用户开网页就行。

**Windows 想有个「桌面图标」怎么办？** 没有 Windows 安装包。办法：Chrome / Edge 打开网址 → 菜单 →「安装此站点为应用」→ 桌面出现独立窗口的快捷方式。
它打开的还是**线上那个网页**（所以永远是最新版），断网就打不开；要离线用就存一份本地页面（见下面「原理」）。

## 原理

界面是一张 HTML 页面，播放交给浏览器原生的 `<video>`。解码器是浏览器自带的（H.264 / HEVC / AV1 等），所以不需要转码；页面本身不请求任何服务器（全页没有一个外部链接，图标都是内嵌的），视频也只从你本地读取。

所以你只要手里有这张 HTML 文件（仓库里的 `src/view.html`，或 zip 里的那一份），双击就能用，**完全断网也能放本地视频** —— 网页版唯一做不到的就是这一点。

## 改代码：先预览，再上线

推上去就等于线上立刻更新 —— 没有灰度、没有"只给测试用户看"这回事。所以改完先在本机看：

```zsh
./preview.sh        # 只在本机能打开的地址，默认 http://127.0.0.1:8760/，⌃C 停
```

看没问题，再把 `src/` 同步进 `docs/` 并推上去。

- `src/view.html` 是唯一的真源；网页上的那一页是 `docs/index.html`，**是它的拷贝**（GitHub Pages 只认 `docs/`）。
- `docs/sw.js` 管离线缓存。它必须放 `docs/` 根目录，页面才注册得到。
- 离线缓存是**网络优先**：有网永远拿最新那份，只有断网才用存下来的。反过来会让用户一直看到旧版。

## FAQ

- **Windows 能用吗？** 能，用浏览器打开那个网址就是完整功能，不需要安装任何东西。
- **手机上能看本地视频吗？** 能。手机浏览器打开网址 → 选「文件」里的视频（受手机浏览器支持的格式限制）。
- **为什么不能播 Netflix / 爱奇艺？** 那些是 DRM 加密流，任何浏览器套壳都解不开（源被锁死，不是工具的问题）。
- **字幕不显示？** 默认会自动挂同目录同名字幕；也可以按 S 手动选 `.srt` / `.vtt`。
- **网页版能记住我看哪儿吗？** 能。记录存在你自己浏览器的本地存储里（不上传）。但「单个视频文件」的记录刷新后就失效——浏览器不允许网页在刷新后重新打开你硬盘上的某个文件，这是安全限制；用「打开文件夹」选整部剧，记录就能稳定跨刷新。
